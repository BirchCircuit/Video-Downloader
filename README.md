# Video-Downloader
An easy to use video downloader app that can download from hundreds of different websites without needing to go onto dodgy downloader sites.

## To install:

- Download the latest `VideoDownloader.zip` file from the **[Releases page](https://github.com/BirchCircuit/Video-Downloader/releases/tag/v1.0)**.
- Once the ZIP has downloaded, extract it and then follow the instructions inside "Video downloader instructions.pdf."

### Notes
- Currently supported natively on Windows only.
- Only download directly from this page if you want to edit the source code as it doesn't contain the extra `.exe` files needed to run the app properly.

*Please note this is a vibe coded app.*
